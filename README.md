# Modern-Landing-Page-Design

## About the project

This project is a landing page concept focused on a clear visual hierarchy, clean layout and a user-friendly experience. The goal was to practice the full design process: from structure and wireframes to the final visual design.

## Page structure

- **Hero section**: main message and call-to-action
- **Features**: key benefits presented clearly
- **About / How it works**: short explanation of the product or service
- **Social proof**: reviews or testimonials
- **Contact / CTA**: final call-to-action and footer

## Design details

- **Tool:** Figma
- **Typography:** FONT_NAME
- **Color palette:** main colors (add HEX codes)
- **Grid:** 12-column grid, responsive layouts for desktop, tablet and mobile
- **Approach:** UX/UI best practices, consistent spacing, accessible contrast

## What I practiced

- Building layouts with auto layout and components in Figma
- Creating a consistent design system (colors, fonts, buttons)
- Designing for different screen sizes
- Improving visual hierarchy and readability
